# JournalPilot

JournalPilot is a manuscript submission and peer-review management platform for academic journals.

## Development

```powershell
npm run dev
```

Open `http://localhost:3000`.

## Verification

```powershell
npm run lint
npm run typecheck
npm run build
```

## Agent Notes

Before changing Next.js code, read the installed version-matched docs in `node_modules/next/dist/docs/`. Product and implementation requirements live in `journalpilot_prd.md` and `implementation_prompt.md`.
